# Системаи тарроҳӣ
- Рангҳо: `ui/Theme.kt` → `Palette` (Accent фирузагӣ, AccentAlt бунафш, Gradient).
- Компонентҳо: `ui/Components.kt` — `AppCard`, `Callout`, `GradientButton`, `SoftButton`, `ProgressRing`, `ProgressBar`, `CodeBlock`, `CodeEditor`, `Pill`, `BadgeCircle`.
- Ҳайлайти код: `highlightPython()` дар `Components.kt` (дарозии матнро тағйир намедиҳад, барои `VisualTransformation` бехатар аст).
- Матнҳо: `ui/Texts.kt`.
- Нукта: нишонаҳо танҳо аз `material-icons-core` истифода мешаванд (бе вобастагии иловагӣ).
